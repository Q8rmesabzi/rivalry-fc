# Rivalry FC

A mobile-friendly FIFA tournament tracker for Parsa and Samyar.

To publish, upload `index.html`, `manifest.webmanifest`, `icon.svg`, `icon.png`, and `icon-512.png` from the prepared app package to the repository root, then enable GitHub Pages under Settings → Pages → Deploy from branch → main / (root).

The app saves tournament data locally on each device. Export backups regularly.
