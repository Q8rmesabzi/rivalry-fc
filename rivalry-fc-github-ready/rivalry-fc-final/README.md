# Rivalry FC

Static 64-team FIFA tournament tracker. No server or build required.

## Free GitHub Pages publishing
1. Create a **public** repository named `rivalry-fc`.
2. Upload **all files in this folder** into the repository root (not the ZIP file).
3. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, `main`, `/ (root)`, then Save.
4. Open `https://YOUR-USERNAME.github.io/rivalry-fc/` in Safari.
5. Tap Share → Add to Home Screen.

## Features
- Up to 64 clubs; bulk entry and assign to Parsa or Samyar
- Common club crest auto-matching using Wikimedia Commons file paths, manual HTTPS logo override, fallback initials
- Custom fixtures and editable results
- Six-round, 64-team knockout bracket with automatic advancement
- Manual 0.5-point awards, automatic player goals, stats
- Local browser storage and JSON backup/import

## Important
Scores are stored in the browser on that device. They do not sync between devices. Export backups periodically. Club logos require internet and external image availability; not every logo will resolve. GitHub Pages hosts the static app, not your scores.
